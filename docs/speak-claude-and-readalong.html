speak-claude and readalong

Two separate tools that use the same free voice on your Mac. speak-claude reads Claude's replies out loud. readalong reads whole documents and highlights each word as it goes.

How they're tied together

Very loosely. speak-claude's voice command has one sub-command, voice read, and all it does is pass your file on to readalong. These three lines are the whole connection:

read)  shift
       command -v readalong || { echo "voice read needs readalong: ..."; exit 1; }
       exec readalong "$@" ;;

Nothing else is shared: not code, not settings, not the voice files. Each tool installs and works without the other. You can also skip voice read entirely and run readalong notes.pdf yourself.

Reading documents used to be part of speak-claude. It moved out into readalong so speak-claude could stay small and do one job.

Using readalong

voice read and readalong are the same command. Both always need a file to read, and any options go after the file name:

voice read paper.pdf                 # opens a reading page in your browser
voice read paper.pdf --terminal      # reads in the Terminal instead
voice read paper.pdf --start         # from the beginning, not where you stopped
voice read paper.pdf --speed 1.3     # 0.5 to 2.0, remembered next time
voice read paper.pdf --voice am_fenrir
readalong voices                     # list the voices
voice read --help                    # all of the above

While it reads: space pauses, b goes back about a minute, the arrow keys move a sentence, + and − change speed, t shows the contents, f dims everything but the current sentence, esc stops. It remembers your place, so the next time you open the same file it offers to carry on.

Common mix-up: voice read --a doesn't work, because readalong got no file to read. The short letters a, s, p, r belong to speak-claude and go straight after voice: vo a repeats Claude's last reply.

Good to know

Inside Claude Code, start with !

Typing ! vo s runs the command right away. Without the !, the words are sent to Claude as a message.

Without readalong

speak-claude works fine on its own. voice read then just prints where to get readalong.

Silent from the start

Start Claude Code with SPEAK=0 claude and that session never speaks.
