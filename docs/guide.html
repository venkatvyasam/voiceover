01What it does

Every time Claude Code finishes a reply, you hear it read aloud a few seconds later. Code blocks, tables and headings are skipped, because they sound bad when spoken; you still see them on screen. When you send your next message, the old reply stops talking.

Nothing leaves your computer. The voice is Kokoro, a small open text-to-speech model that runs on your Mac's processor. You download it once during setup; after that it works offline.

Good to knowClaude Code has voice dictation built in: you speak, it types. It can't talk back, though. This tool adds that half.

02Before you start

  • A Mac with macOS 13 (Ventura) or later. Check under Apple menu → About This Mac.
  • Claude Code, installed and working. claude --version should print a version.
  • About 500 MB of free disk space, and internet for the setup only.

Which kind of Mac do you have?

Both kinds work, and setup is the same. If you're curious, run this in Terminal:

uname -m

arm64 means Apple Silicon (M1, M2, M3, M4). x86_64 means Intel.

Install uv, if you don't have it

uv manages Python for this tool, so you don't have to. Check with uv --version. If that fails, install it, then open a new Terminal window:

curl -LsSf https://astral.sh/uv/install.sh | sh

Get access to the code

The code is in a private GitHub repository. Accept the invitation email from GitHub first. Then install the GitHub command-line tool from cli.github.com (or brew install gh if you use Homebrew) and sign in:

gh auth login

03Install

  1. Download the code into a folder in your home directory:

    gh repo clone venkatvyasam/speak-claude ~/speak-claude
cd ~/speak-claude

  2. Run the installer. It takes a few minutes the first time, mostly downloading the voice model.

    ./install.sh

    It installs the Python packages inside the folder, downloads the voice model, adds a voice command (and its short form vo), and registers two hooks in ~/.claude/settings.json. It backs that file up first. At the end you'll hear "Hello! The Claude Code voice-over is installed."

  3. If the installer says ~/.local/bin is not on your PATH, run the line it prints, then open a new Terminal window. That makes the voice command work everywhere.

Keep the folder where it isThe hooks point at this folder. If you move or rename it, run ./install.sh again from the new location.

04Try it

Start a new Claude Code session and ask something with a medium-length answer:

claude
Then type
Explain in one short paragraph what a Claude Code hook is.

About three seconds after the answer appears, you should hear it.

Very short replies, under 120 characters, are skipped on purpose. They're usually status messages like "Done."

Heard nothing? Run voice status and see Troubleshooting.

05Everyday controls

Everything goes through one command, voice, followed by what you want it to do. vo is a short form, and each word has a one-letter shortcut. Run it in any Terminal window, or inside Claude Code by typing ! first, like ! voice pause. The ! runs it as a shell command instead of sending it to Claude.

CommandShortWhat it does
voice stopvo sStop speaking now
voice pausevo pPause, even before the first sound
voice resumevo rContinue where it paused
voice againvo aSay the last reply again (instant)
voice statusWhat's muted, what's playing, and why the last reply was spoken or skipped
voice mute / unmuteMute / unmute every session
! voice mute here / unmute hereMute / unmute only the Claude Code session you type it in
SPEAK=0 claudeStart a session that stays silent
voice helpShow this list

Speech stops by itself when you send your next message. The exception is a message that starts with voice or vo, so typing a voice command to Claude still works. If several Claude Code sessions are open, the newest reply interrupts the older one.

Pausing from inside Claude CodeBy default, Claude replies after a ! command, and that reply gets read aloud over what you just paused. To stop that, add "respondToBashCommands": false to ~/.claude/settings.json, or run voice commands from a second Terminal window.

06Using it for learning

Voice helps most when your eyes are somewhere else. Some ways to use it:

  • Step away during long tasks. Ask Claude to run your tests or refactor something, go get water, and hear the result when it's done.
  • Listen while you look at the code. Ask "walk me through what this function does", then follow along in the file while the explanation plays.
  • Ask for spoken-length answers. "Explain recursion in three sentences" sounds much better than a reply full of tables.
  • Replay the hard parts. voice again plays the last reply again instantly.
  • Rest your eyes during long study sessions.

It doesn't help when you're already reading the reply on screen. While coding hard, mute it with voice mute and unmute later with voice unmute.

07How it works

Hooks: your code runs at moments Claude Code chooses

Claude Code can run your own commands at points in its lifecycle, such as "a reply just finished" or "the user just sent a message". These are called hooks, and they're listed in ~/.claude/settings.json. After installing, yours contains:

~/.claude/settings.json (excerpt)
"hooks": {
  "Stop": [{ "hooks": [{ "type": "command",
    "command": "\"…/speak-claude/.venv/bin/python\" \"…/speak-claude/speak_reply.py\"" }] }],
  "UserPromptSubmit": [{ "hooks": [{ "type": "command",
    "command": "\"…/speak-claude/voice\" --on-prompt 2>/dev/null || true" }] }]
}

The two hooks give two paths through the tool:

When a reply finishes
Claude Codefinishes a reply, runs the Stop hook
→
speak_reply.pychecks mutes, picks the text, cleans it for speech
→
speak.pyKokoro turns text into audio, chunk by chunk
→
afplaymacOS plays each chunk
When you send a message
Claude Coderuns the UserPromptSubmit hook
→
voice --on-promptstops the old speech

What the Stop hook receives

Claude Code sends the hook a small JSON object on standard input. The two fields this tool uses are the reply text and the session ID:

{
  "session_id": "25d0e2d2-d558-4dfb-…",
  "hook_event_name": "Stop",
  "last_assistant_message": "Recursion is when a function calls itself…",
  …
}

What speak_reply.py decides, in order

  1. Is everything muted (voice mute), was the session started with SPEAK=0, or is this session muted (voice mute here)? Then stop here.
  2. Is the reply under 120 characters? Skip it.
  3. Clean it for listening: drop code blocks, tables, headings and quotes; remove markdown symbols; keep list items; cut very long replies at 5000 characters.
  4. Stop any older reply that's still talking.
  5. Start speak.py as a separate background process and exit immediately. A hook should never make Claude Code wait.
  6. Write one line to speak.log saying what it did and why. voice status reads this.

Why the first sound comes so quickly

Turning a long reply into audio in one go would take 40 seconds of silence on a laptop. Instead, speak.py splits the text into chunks. It generates the next chunk while the current one plays. Kokoro generates speech about twice as fast as it plays, so each chunk is allowed to be at most 1.8 times as long as the one before it. That keeps the next chunk ready before the current one ends, so there are no gaps.

How pause and stop work

Each chunk plays through afplay, the Mac's built-in audio player. voice pause sends the signal SIGSTOP to both the audio player and the speech generator, which freezes them mid-sound; voice resume sends SIGCONT to unfreeze them. A frozen process can't exit, so voice stop sends both a stop signal and SIGCONT.

The log

Every reply leaves one line in speak.log, in the tool's folder:

--- Sun Oct 11 11:20:39 2026 [25d0e2d2] spoke 965 chars (payload): 'Recursion is when…'
--- Sun Oct 11 11:24:02 2026 [25d0e2d2] skipped: reply too short (14 chars, minimum 120)
--- Sun Oct 11 11:30:15 2026 [7f3a91c0] skipped: this session muted (! voice unmute here)

08Make it yours

All settings are constants at the top of two files. Changes apply from the next reply; no restart needed.

Pick a voice

Kokoro has 28 English voices. Hear them all say the same sentence (run inside the speak-claude folder):

.venv/bin/python audition.py af_ am_      # American women, American men
.venv/bin/python audition.py bf_ bm_      # British women, British men
.venv/bin/python audition.py af_heart am_fenrir bm_fable   # compare a few

Then set VOICE at the top of speak.py, for example VOICE = "am_fenrir". The default, af_heart, is one of the most natural. am_fenrir and bm_fable are good male voices.

Other settings

09Troubleshooting

Start with voice status. Its last line says whether the most recent reply was spoken or skipped, and why.

What you seeWhat to do
Status says "MUTED"Run voice unmute, or ! voice unmute here for the current session.
"reply too short"Expected for replies under 120 characters.
"nothing logged yet"The hooks haven't run. Start a new Claude Code session. Type /hooks in Claude Code to check that they're listed. If not, run ./install.sh again.
It worked, then stopped after you moved the folderRun ./install.sh again from the new location.
voice: command not foundAdd ~/.local/bin to your PATH (the installer prints the line), then open a new Terminal window.
Speech cuts off mid-sentenceAnother Claude Code session finished a reply (newest wins), or you sent a message. Use voice again to hear it again.
Status says "spoke" but you heard nothingCheck your Mac's volume and output device. Error messages from speak.py appear in speak.log.

10Uninstall

cd ~/speak-claude
./uninstall.sh

This removes the two hooks (after backing up your settings) and the voice and vo commands. To remove everything, including the 340 MB model, delete the folder afterwards.

11Ideas to build next

The code is short and commented, which makes it a good place to practise. Try these with Claude Code's help:

  • Summary mode. Speak only the first paragraph of each reply, and add voice brief / voice full to switch.speak_reply.py · the speakable() function
  • Hear when Claude needs you. Add a Notification hook that says "Claude needs your input" when it's waiting for permission.a new hook in settings.json · see the hooks docs
  • Change voice from the command line. voice use am_fenrir, stored in a small settings file instead of edited in code.voice and speak.py
  • Say "see the code on screen" where a code block was skipped, so you know something was there.speak_reply.py · speakable()
  • Port it to Linux. Replace afplay with paplay or aplay.speak.py and voice
